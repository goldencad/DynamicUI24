# Operations

`OperationCoordinator` owns bounded UI projection keyed by stable `OperationId`; providers own work, persistence, cancellation effects, retry safety, and business status. Generic state is Pending, Running, Succeeded, Failed, Cancelled, or NeedsAttention. Cancel/Retry are capability- and state-driven. Navigation can reattach to retained truth by ID. Safe titles, steps, diagnostics, notifications, accessibility, and history must already be P1-safe. Completion projects through `IOperationNotificationProjection`, an adapter seam for the existing Notification Coordinator. Never fabricate percentages. Test with `dotnet test --filter ModernWorkspaceFoundationTests`. Common failures are tying truth to controls, accepting stale generations, assuming rollback/idempotence, or leaking filenames.
