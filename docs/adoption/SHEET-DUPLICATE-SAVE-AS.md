# Adopt Duplicate and Save As

Provide `ISheetLifecycleProvider` for transactional physical work and `ISheetCalculationCompatibility` backed by the authoritative calculation engine. Allocate a fresh `SheetCode`; returning the source or an existing identity is rejected. Duplicate typically uses `DuplicateFull`; a logically new context may use the generic `NewDataContext` profile and explicit mappings. Providers—not DynamicUI24—copy values, generate RowKeys and interpret target context.
