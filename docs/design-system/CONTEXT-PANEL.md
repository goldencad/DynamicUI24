# Context Panel Design System

The panel is a secondary right-side region; the workspace remains dominant. Use semantic surface, border, text and accent tokens. The header contains a localized title and accessible close action. Sections use compact tabs or vertical groups. Loading, empty and error states stay within the panel and never block the workspace.

Width is user-resizable within definition bounds and the shell’s main-workspace minimum. Keyboard focus is visible; F1 opens contextual help/panel, Escape does not destroy selection, and the splitter remains focusable. Never expose a protected raw value in text, tooltip, copy or accessibility output.
