# Motion guidance

Normative authority: [v0.16 §7](../specification/DynamicUI24-Spec-v0.16.md#7-motion-effects-and-accessibility).

Choose `Motion.None`, `Fast`, `Standard`, or `Emphasized` by interaction purpose. Themes own milliseconds and easing. Prefer no motion for bulk data changes; use restrained motion to clarify reveal or state transition. Resolve reduced-motion preference to None or the least disruptive recipe.
