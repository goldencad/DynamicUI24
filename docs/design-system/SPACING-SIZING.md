# Spacing, sizing, and density guidance

Normative authority: [v0.16 §§6, 16](../specification/DynamicUI24-Spec-v0.16.md#6-spacing-sizing-and-density).

Select the semantic relationship first, then resolve it to the base `Space.*` scale. Select width by value behavior; compact dates, booleans, and short codes should not stretch. Use Compact, Standard, or Comfortable density at a containing surface, not as business metadata.

Legacy `DuiSpacing*` values remain compatibility resources during phased retrofit.
