# Developer Mode

Developer Mode is a protected workspace, never a hidden-shortcut feature. Opening, editing, previewing, publishing, rollback and authorization-binding edits use separate semantic capabilities.

The primary layout is Search/Command above Semantic UI Tree, Live Preview and Definition Inspector panes. Inspector sections use progressive disclosure for General, Layout, Editor, Authorization and Help. Preview visibly says DRAFT/PREVIEW, reuses runtime renderers, supports vi-VN/en-US and System/Light/Dark, and is not a P1 bypass. Avoid a WinForms-style property grid, absolute positioning and arbitrary-control placement.
