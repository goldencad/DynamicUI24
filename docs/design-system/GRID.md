# Shared Grid guidance

Normative authority: [v0.16 §11](../specification/DynamicUI24-Spec-v0.16.md#11-grid).

Use the `GridRole` taxonomy for shared anatomy and state. DataEntry and Report grids may differ in editing/business semantics while resolving typography, padding, focus, selection, validation, hierarchy, and density through the same Standard. Preserve `RowKey + VariableCode`; visual coordinates are never identity.
