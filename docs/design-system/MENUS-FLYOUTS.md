# Menu and Flyout guidance

Normative authority: [v0.16 §14](../specification/DynamicUI24-Spec-v0.16.md#14-menus-flyouts-panes-notifications-and-help).

Build menus from shared semantic commands/definitions. The presentation layer owns rows, checks/icons, separators, shortcuts, destructive and disabled treatment, nesting, focus, keyboard behavior, and accessibility. Application code does not supply an equivalent local menu style.
